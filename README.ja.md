# 焼いたあとに · MiniDisc ラベル スタジオ

MiniDisc 用の静的ラベルエディター：6言語UI、ランタイム依存ゼロ、SELPHY サイズ用紙への正確な 300 DPI 印刷向けに設計。すべてのジャケットとプロジェクトはお使いのマシンに留まります——バックエンドなし、分析なし、外部フォントリクエストなし。オプションのオンライン検索はデフォルトでオフ。有効にすると、入力した検索語が選択したサービスへ直接送信されます。[サイトを開く](https://bithostgits.github.io/md-label-studio/)。

コードは独立実装です。オリジナルの MiniDisc ロゴは権利者が権利を留保する单独アセットとして収録しています。`THIRD-PARTY-NOTICES.txt` を参照してください。

## 主な機能

- **A/B/C/D の4セット独立ラベル**：セットごとにアルバム・アーティスト・年・ジャケット・フォント・テーマ・大文字・ヘッダー非表示・サイズを個別設定。デフォルトは1枚に4セット印刷。従来の2セット A/B レイアウトも選択可能で、切り替えても C/D は失われません。
- **オリジナル幾何**：表面 38×54 mm、ヘッダー 5 mm、ジャケット 38×38 mm、背表紙 58×3.5 mm。生成されるすべてのラベルに **0.10 mm の内蔵トンボ**。
- **300 DPI 書き出し**：4セット用紙 100×148 mm → 1181×1748 px、実ミリ表面 449×638・背表紙 685×41、旧互換 448×637、無補正の双軸キャリブレーション用紙。すべて `pHYs` = 11811 px/m 付き。
- **オプションの Hi-MD マーク**（セット単位）：表面は MiniDisc ロゴの横に横長 Hi-MD マーク、背表紙は右寄せバー。本物の Hi-MD ワードマークを使用し、権利は留保されています。
- **6言語UI**（デフォルトは英語。他に 简体中文、繁體中文、Español、Français、日本語）。言語ごとに適合するオフラインフォントを提供。言語を切り替えてもラベル内容や書き出しバイトは変わりません。
- **オプションのオンライン検索**（デフォルトオフ）：MusicBrainz の2段階検索または iTunes メタデータのみの候補、段階別の進行表示と各段階の再試行ボタン、Cover Art Archive からのジャケット取り込み（解像度警告付き）。手動アップロードは常に利用可能。ブラウザーからサービスへの直接リクエストのみで、プロキシもキーも使いません。
- ローカルプロジェクト JSON v2 の保存／読み込み（4セットのアップロード済みジャケットを含む）。旧2セットプロジェクトと互換。

## ローカル実行

`app/`（または解凍したリリースのルート）で：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

`http://127.0.0.1:8080/` を開いてください。`file://` では開かないでください（ESモジュールとフォントマニフェストがブロックされます）。`npm install` は不要です。開発テスト：`npm test`、`npm run test:browser`、`npm run test:fixes`、`npm run test:logo`、`npm run test:four-set`、`npm run test:spine`、`npm run test:himd`、`npm run test:i18n`、`npm run test:autocomplete`。ビルド：`npm run build`（許可リストのファイルを `dist/` へコピーし SHA-256 マニフェストを生成）。

## 印刷の注意

- デフォルトの用紙は**仕上がり 100×148 mm**（ミシン目付き 100×177 ではありません）。表面アンカー：A(9,6)、B(53,6)、C(9,62)、D(53,62)。背表紙は x21、y118/123.5/129/134.5。安全マージンは最低 6 mm。無効なカスタムレイアウトは自動縮小せず拒否します。
- オプションで真正的な 4×6 インチ（101.6×152.4 mm → 1200×1800 px）も選択可能。SELPHY 用紙であるとは主張しません。
- キャリブレーションはデフォルトで無補正です。テスト用紙を印刷して測定し、`factor = 50 / 実測値` を入力してください。試し印刷なしに実物への適合は保証できません。
